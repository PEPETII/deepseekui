# 工单：单条提问时显示大纲面板

## 一、任务目标

放宽大纲面板显示阈值：会话只有 1 个 Q 条目（且 AI 回复无小节标题）时也显示面板，不再整体隐藏。版本 `0.3.33` → `0.3.34`。

## 二、缺陷/需求根因

`content.parts/11-outline.js` 的 `buildOutline` 中 `items.length < 2` 即 `display:none`：短会话（1 问 + 无标题回复）永远只有 1 条 `Q1`，面板被隐藏，用户误以为大纲故障。该行为系原有设计，与首条回复流式误判工单（已执行）无关。

## 三、本次涉及的功能

- 大纲显示门槛：`< 2` → `< 1`（0 条仍隐藏）。

## 四、本次不涉及的内容

- 大纲条目构建、签名比对、scrollspy、过滤、原生目录核对；classify/角色判定；popup 逻辑；存储键；权限。

## 五、前置条件

- 用户确认"需要有 Q 就显示大纲"（2026-09 会话）。

## 六、代码影响范围（白名单）

- 允许：`content.parts/11-outline.js`（仅阈值行 + 注释）、`content.parts/00-runtime.js`（仅 VERSION）、`manifest.json`（仅版本）、`popup.parts/00-core.js`（仅 POPUP_VER + 头注释）、`popup.html`（仅徽标）、`AGENTS.md`/`docs/*`。
- 禁止：其余一切代码文件、`background.js`、CSS、权限/host。

## 七、任务拆解

### Task 1 阈值修改（11-outline.js:235）

`items.length < 2` → `items.length < 1`，加注释说明语义。

### Task 2 版本同步

三处版本 + popup 徽标 + `00-core.js` 头注释 → `0.3.34`。

### Task 3 验证

`node --check`、行数门禁、全部单测、`manifest.json` JSON 解析。

## 八、测试计划

- 正常路径：1 问短会话 → 面板显示 `Q1`；多问带标题会话 → 行为不变。
- 边界：空会话（无 turn）→ 面板不显示（原逻辑保留）；`docdeep_outline=false` → 面板移除（原逻辑保留）。

## 九、回归测试范围

大纲开关、侧栏过滤、查找 ↑↓、导出 MD/JSON、开关启停恢复原站、行数门禁。
