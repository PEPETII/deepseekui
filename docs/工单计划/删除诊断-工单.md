# 删除工单：移除“诊断”界面及诊断自证链路

## 一、删除目标

删除“诊断”功能全链路：`popup.html/js` 的诊断分区（Tab + 运行状态 pane + `#check` 检测状态 + `#diag` 结果区 + `#report` 复制诊断报告）与配套样式（`.diag` 系、`--ok/--bad` 令牌、`@keyframes spin`、`.btn-mini`）；`content.js` 的诊断自证生产端（`snapshot()` 快照、`heartbeat()` 4s 心跳写 `docdeep_heartbeat`、`DOCDEEP_PING` 消息直回、`window.__DOCDEEP__` 全局暴露、诊断专用适配层 `nativeOutlineSnapshot()`）。旧用户本地的 `docdeep_heartbeat` 键由 popup `load()` 主动 `remove` 清理。版本同步 `0.3.20`。

## 二、本次删除涉及的功能

- 诊断自证（运行状态检测 + 诊断报告复制）：整功能删除，含消费端（popup 分区/交互/样式）、生产端（快照/心跳/PING/全局暴露）、存储键与版本一致性自动判定。
- 连带清理：`nativeOutlineSnapshot()` 仅供快照消费，随快照删除；popup 中 `lastPing/lastHeartbeat` 状态随之删除。
- 其他功能（阅读/操作/收藏三分区、导出、查找、大纲、键盘导航、原生目录隐藏、格式工具栏）：不碰。

## 三、本次不删除的内容

- `probeNativeOutline()` 本体：原生目录隐藏打标（功能 12）、大纲补全计数、原生对账仍依赖，仅其返回对象中 `labelsHash/containerSig/sample/refs` 等原诊断快照字段不再有消费方，按最小侵入原则保留不动。
- `#docdeep-ver` 版本角标（页面工具条内“文档化 v0.3.x”）：属工具条常驻 UI 元素，非诊断模块。
- `background.js` 全部、`content.css` 全部（诊断无落点）。
- `PAPER-WIDTH-001` 冻结区、`classify/mergeQuestionOrder/collectAllTurns` 算法本体、收藏全链路、导出三格式、消息协议其余类型。
- `manifest.json` 权限/host；`docs/known-issues.md` 历史结论不改写（历史条目中 widthProbe/快照字段记载保留，另追加本次删除记录）。
