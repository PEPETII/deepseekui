# 模板背景图工单

## 一、目标

在 popup 的【模板】分区增加背景图配置能力：可开启/关闭背景图，上传、预览、重新上传、删除本地图片，并把配置与模板包导入/导出关联。

## 二、范围

- 使用已有 `assets/backgrounds/main-background.png` 作为无自定义图片时的默认背景。
- 自定义图片支持 PNG/JPG/JPEG，单张不超过 5 MB；推荐 1920×1080、16:9，非 16:9 允许上传并由页面 `cover` 适配。
- 新增本地设置对象 `docdeep_template_background`，默认开启以保持已有背景功能行为；关闭只恢复站点默认页面底色，不删除已上传图片。
- 新增模板 JSON 导出/导入，图片以 data URL 内嵌，导入后恢复主题、开关和背景图。

## 三、明确排除

- 不增加远程上传、账号同步、网络请求、host 权限或第三方依赖。
- 不修改 DeepSeek 原生 textarea/form/发送按钮，不改 `background.js` 下载协议。
- 不把对话正文写入模板包；不扩展为壁纸库、在线分享服务或多模板编辑器。

## 四、实现位置

- `popup.html`：模板区开关、规格说明、预览、上传/删除、模板导入/导出控件及样式。
- `popup.parts/00-core.js`：默认值、背景配置规范化、文件限制常量、收藏导出兼容字段。
- `popup.parts/02-themes.js`：模板区恢复时同步背景状态。
- `popup.parts/03-background.js`：背景文件读写、预览、反馈、模板包构造/解析/导入导出。
- `popup.parts/03-entry.js`：加载顺序、DOM 接线和 Node 测试导出面。
- `content.parts/00-runtime.js`、`13-entry.js`：背景设置合并与 storage 变化同步。
- `content.parts/12-page-background.js`：按开关选择默认资源或本地 data URL。
- 自定义 data URL 使用注入图片节点的 `img.src` 渲染，避免大图片进入 CSS 自定义属性后受浏览器值长度限制；内置 PNG 保持 CSS 背景路径。
- `tests/template.test.js`：纯函数、非法输入、大小/格式、模板包往返测试。

## 五、数据模型

```json
{
  "docdeep_template_background": {
    "enabled": true,
    "dataUrl": "",
    "mimeType": "",
    "name": "",
    "size": 0,
    "width": 0,
    "height": 0
  }
}
```

缺失或损坏配置回退到默认开启、无自定义图片；自定义 data URL 必须是 PNG/JPEG base64 且不超过 5 MB 对应长度上限。

## 六、交互与异常

- 开关使用 `role="switch"` + `aria-checked`，同时显示“已开启/已关闭”。
- 上传过程禁用上传按钮并显示“正在读取”；成功显示尺寸和文件名，失败明确区分格式、大小、读取失败和存储失败。
- 成功上传后自动开启并立即预览；已上传图片仍可手动关闭，关闭状态保留图片，重新开启后继续使用。
- 删除只清除自定义图片，开启状态下回退到内置默认背景。
- popup 关闭/刷新后从 `chrome.storage.local` 恢复；页面通过 `DOCDEEP_SETTINGS` 和 `onChanged` 即时同步。

## 七、模板包

- 导出包 `app=docdeep`、`kind=template`、`version=1`，包含 `template.id/theme/background`。
- 导入只接受有效模板包，复用主题白名单和背景配置校验；图片无效时不写入旧配置。
- 模板包可作为分享文件携带背景图；不包含对话正文、账号或 Token。

## 八、验收标准

- 正常路径：开关切换、默认图显示、自定义 PNG/JPG 上传预览、重新上传、删除、刷新恢复、模板包导出→清空→导入一致。
- 边界：空/非法类型、超过 5 MB、伪造图片内容、损坏模板 JSON、无背景字段、存储失败；旧配置缺少新键仍可用。
- 页面：启用时实际背景显示，关闭时背景节点移除；三主题、SPA、新旧会话、打印和扩展关闭清理不回归。
- 静态：所有源文件不超过 600 行，新增 CSS 规则符合 `html[data-docdeep="on"]` 约束，无新增权限。

## 九、风险与回滚

- 5 MB 图片转 data URL 后会膨胀，若本地配额不足则保留旧配置并提示失败；不吞掉错误。
- 回滚只需移除新增模板控件、脚本和新 storage 字段读取；旧背景默认路径仍保持可用。

## 十、与原计划差异

- 原模板专题只承载主题档位，本工单在其上增加本地背景对象和模板包导入/导出，是用户本次明确提出的范围扩展。
- 仍不引入远程分享或在线壁纸系统，图片只在本地和用户主动导出的 JSON 文件中流转。
