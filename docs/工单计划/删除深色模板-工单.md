# 删除工单：移除「模板」分区的外观模板「深色」卡

## 一、删除目标

删除 popup「模板」分区中的「深色」卡及其配套实现：`popup.html` 的 `data-skin="mo"` 卡片与 `data-preview="mo"` 预览样式、`popup.parts/02-themes.js` 的 `TEMPLATES` 中的 mo 项。删除后模板分区仅剩「橙色」一档。版本同步 `0.3.40`。

## 二、本次删除涉及的功能

- 「深色」模板卡：展示（卡片 DOM + 预览缩略图样式）与清单项（`TEMPLATES` mo 条目）完整移除，含关联 UI（选中态 `paintTemplates` 对 mo 的命中）与单测断言同步。
- 白名单校验重构：`applyTheme` 的档位白名单从 `TEMPLATES ∪ bai` 改为新增 `THEME_SLOTS = ['mi', 'bai', 'mo']`，保证「阅读」下拉仍可切墨色/纯白。
- 其他（阅读/操作/收藏三分区、导出、查找、大纲、键盘导航、原生目录隐藏、格式工具栏、收藏全链路）：不碰。

## 三、本次不删除的内容

- 墨色主题机制本体：`content.parts/*` 的 `data-doctheme="mo"` 令牌分支、`applySettings/setOn` 的 `docdeep_theme` 落盘与读取，一律不动。存量 `mo` 用户打开面板不受影响（模板区不误高亮）。
- popup 面板深色分支：`popup.html` 的 `:root[data-theme="dark"]` 令牌与 `paint()`/`applyTheme()` 的 `dataset.theme` 同步保留——「阅读」下拉切墨色时面板仍跟随变深。
- 「阅读」分区的纸张主题下拉：保留 `mi/bai/mo` 三档。删除下拉会造成墨色/纯白不可达的功能回退（属 breaking change），按兼容方案保留。
- `background.js`、`manifest.json` 权限/host、`docs/known-issues.md` 历史结论（只追加，不改写）。
- 工作区已有与本轮无关的未提交修改（v0.3.39 Enter 绑定补漏等）：不删除、不覆盖、不混入本轮 diff。
