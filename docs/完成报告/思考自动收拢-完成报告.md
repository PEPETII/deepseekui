## 4. 关键状态转换

- **思考中**：有 `.ds-think-content` 且无 `.ds-assistant-message-main-content` → 不干预（CSS 时间窗维持现状）。
- **转换沿**：回答正文挂载且思考片段仍挂载 → 向组容器 `firstElementChild`（原生标题行 `pj`）派发一次 `click` → 站点自身翻转 `isShowDetail`、卸载片段、标题切「已思考（用时 N 秒）」+ 箭头可用。
- **一次性**：标题行元素入 WeakSet（同挂载只点一次）；key 计数 ≤3 止损。
- **用户接管**：文档捕获监听只认 `isTrusted` 且命中标题行的点击 → 记 `'user'`，此后（含虚拟列表重挂）永不代点。扩展自身合成 click `isTrusted=false`，天然自滤。
- **重挂**：全新元素 + 同 message-id + attempts<3 → 允许再代点（站点重挂默认展开，维持收拢符合预期）。

## 5. 为何不会反复强制折叠

1. 收拢后站点卸载片段，`.ds-think-content` 消失，谓词天然失效；
2. 用户重新展开（可信点击）→ 接管监听先行记 `'user'`，classify 侧短路；
3. 同一标题行元素在 WeakSet 中，即使片段重挂也不再代点；
4. MutationObserver→classify（120ms 防抖）每轮都过上述四道闸，无轮询新增。

## 6. 兼容与安全

- 不新增存储键 / 权限 / host；不改消息协议；不碰 `classify` 指纹核心与 `background.js`。
