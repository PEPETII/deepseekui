## 六、关键实现说明

- **追加分段语义**：`composeComposerInsert` 仅在「光标停在非空正文末尾」时补 `\n`/`\n\n` 成空行分段；中段插入、选区替换（即使延伸到末尾）原样落字。此语义由单测钉死（首版实现把「选区替换到末尾」也误判为追加，测试抓出后修正为 `atEnd = start === limit && end === limit`）。
- **富文本一致性**：textarea 仍是唯一 Markdown 底层，写入后 `lastSerialized` 同步再 `syncRichFromTextarea(force)`，避免表面回写竞态；渲染后光标置模型末尾（`modelTextLength`），Markdown 序列化偏移与模型偏移不换算，规避 `RICH-OFFSET-001` 同类风险。
- **摘除性**：按钮带 `INJECTED` 类，`setOn(false)` 兜底 `removeAddToBoxButton()`（ blanket 移除之外的引用清理）；全局监听常驻但惰性（`updateAddToBox` 首行短路 `isOn()`/开关值），总闸关闭后重开无需重绑。
- **重编号**：为保持「文件序号 = manifest 加载顺序」，新文件插入后 6 个 part 序号 +1；全库 grep 确认非存档文件无旧名悬空引用。
