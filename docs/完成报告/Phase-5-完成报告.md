# Phase 5 完成报告（左侧会话栏与原生输入框视觉整合）

## 一、阶段目标回顾

按 `docs/工单计划/Phase-5.md`，将 DeepSeek 左侧会话栏纳入文档化阅读工作台的视觉与布局体系，并补充底部原生消息输入框的 CSS 视觉整合；保持原生导航、折叠、滚动和发送行为，并保证扩展关闭后恢复原站。针对用户反馈的“左侧没有任何变化”补充命中修复，行为版本同步至 `0.3.8`。

## 二、已完成任务

- Task 1：完成左栏探测回退收敛、`/a/chat/s/<id>` 路由识别、普通 `div` 左栏几何/内容密度回退、工作台级侧栏样式、主题令牌、导航反馈、滚动条、响应式间距和打印边界。
- Task 2：完成 JS 语法、manifest JSON、版本同步、CSS 结构、路由、输入框和正常/边界静态断言。
- Task 3：完成白名单、可摘除路径、原生布局保护和实机限制 Review。
- Task 4：完成底部原生输入框外层卡片、textarea、占位符、焦点、发送按钮和禁用状态的主题化视觉规则。

## 三、实际修改内容

- `content.js`：版本更新为 `0.3.7`；新增对 `/a/chat/s/<id>`、`/a/chat/<id>` 和 `/chat/<id>` 的会话路由识别；新增普通 `div` 左栏的左上位置、宽高、可见性和内容密度几何回退；`<aside>` 回退继续增加左侧位置、可见宽度和高度约束，并按左侧位置排序，避免将右侧目录误标为左栏。
- `content.js`：侧栏搜索只从已标记的 `[data-docshell="side"]` 注入，不再在探测失败时退回任意 `<aside>`；外壳缓存允许在节点重建后重新探测。
- `content.css`：将 `[data-docshell="side"]` 纳入文档工作台；新增盒模型、字体、主题背景/边界、导航链接间距、按钮/链接悬停、焦点、当前项、滚动条和窄屏收紧规则；不覆盖侧栏根节点的 `width`、`position`、`display`。
- `content.css`：打印规则新增 `[data-docshell="side"]`，保证非语义侧栏也被隐藏。
- `content.css`：完善 `form:has(textarea)` 原生输入区视觉；外层使用主题表面色、边框、圆角和阴影，textarea 统一文字/占位符/内边距并增加 hover/focus 反馈，发送按钮增加品牌色、悬停、焦点和禁用状态；不改节点、定位、事件或发送链路。
- `manifest.json`、`popup.js`、`popup.html`：版本同步为 `0.3.7`；popup 可见版本由 `0.3.4` 修正为 `0.3.7`。
- `docs/功能扩展规划.md`：新增 Phase-5 路线和功能 11 完成记录。

## 六、关键实现说明

1. 探测链路仍为 `probeShell → probeSideEl → data-docshell="side"`；先识别 DeepSeek 会话路由，再依次使用内联宽度、会话链接 LCA、左侧语义标签、导航标签和几何/内容密度回退，不依赖单一构建哈希类名。
2. 侧栏规则使用 `--dd-surface-2`、`--dd-line`、`--dd-text-2`、`--dd-hover`、`--dd-brand-*` 等既有令牌，因此三主题共用同一实现。
3. 链接采用文档工作台式行间距和当前项反馈；按钮只接管颜色、圆角和焦点反馈，不重建原生操作。
4. 侧栏根节点没有固定宽度、定位或显示模式覆盖，原生展开/折叠仍由 DeepSeek 控制。
5. 侧栏搜索仍是既有 `.doc-search.docdeep-injected` 注入，不新增存储、权限或网络行为；只有左栏已命中并打标时才注入，避免误入右侧目录。
6. 底部输入框只通过 `form:has(textarea)` CSS 选择器处理；发送按钮使用原有语义/末子节点选择器，不增加监听、不修改 `type` 或回车行为；打印仍隐藏原生输入区。

代码级通过：

- `/a/chat/s/<id>`、绝对 DeepSeek 会话 URL 和旧 `/chat/<id>` 路由均可被识别，非会话路径不会误命中。
- 截图对应的左上、窄宽、全高面板夹具满足几何回退条件；右侧大纲位置和过矮面板被排除。
- 左栏正常命中：主题背景、文字、悬停、当前项、焦点、滚动条和响应式规则存在。
- 右侧 `<aside>` 边界：回退要求左侧几何条件，侧栏样式不再直接匹配任意 `<aside>`。
- 搜索注入边界：仅查询 `[data-docshell="side"]`，不再以任意 `<aside>` 作为兜底。
- 原生输入框边界：只修改 CSS 外观，存在 hover/focus/disabled 规则；未新增 DOM、事件监听或消息协议。
- 折叠宽度边界：侧栏根规则不设置 `width`、`min-width`、`position`、`display`，不强制恢复展开。
- 打印边界：同时识别 `[data-docshell="side"]` 和 `<aside>`。
- 版本边界：manifest、content、popup JS、popup 可见版本均为 `0.3.8`。

用户反馈已确认 `0.3.6` 截图中左栏没有明显变化；代码复核确认初版路由匹配未覆盖 `/a/chat/s/<id>`，且初版没有普通 `div` 左栏的几何回退，已在 `0.3.7` 修复。本轮按用户指定继续调整底部原生输入框，版本升至 `0.3.8`。浏览器实机视觉回归仍未完成：现有 Edge DeepSeek 标签已被其他浏览器会话占用，当前会话无法接管，因此不能把输入框实际视觉、标记命中、折叠/主题效果表述为已验证。

## 九、发现的问题

- 已确认：初版实现存在真实的探测覆盖缺口，不能覆盖当前 `/a/chat/s/<id>` 路由和无语义普通 `div` 左栏；本轮已补齐。
- 推断：截图中的左栏为无 `aside/nav` 语义的普通容器；依据是截图形态和当前页面地址，尚缺浏览器运行时 DOM/`outerHTML` 证据。
- 已确认：底部输入框现有代码已经使用 `form:has(textarea)` 视觉入口，本轮在该入口上追加样式；是否命中当前 DeepSeek 构建的实际 textarea/form，仍需浏览器运行时确认。
- 初版测试脚本曾因中文注释定位和检查片段范围错误报错，修正测试脚本后最终断言通过；这些是测试脚本问题，不是源码失败。
